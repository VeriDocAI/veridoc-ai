## ✍️ Contribution Guidelines

All documentation is maintained using **Markdown** following the "Documentation as Code" philosophy.
*   **Location**: All source files exist within the [docs/](file:///c:/Users/Mohmmed%20Aarif/projects/Ai%20ComputerVision/veridoc-ai/docs) directory.
*   **Formats**: Use Mermaid.js block structures for diagramming rather than static image assets.
*   **Updates**: Document modifications must accompany related feature pull requests and pass documentation style criteria.
