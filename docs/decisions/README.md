## 🛠️ ADR Template

When authoring a new ADR, please use the following standard structure:

```markdown
# ADR-XXX: [Decision Title]

## Context & Problem Statement
Describe the technical context, requirements, and what issue we are trying to resolve.

## Considered Options
*   **Option 1**: [Description + Pros/Cons]
*   **Option 2**: [Description + Pros/Cons]

## Decision Outcome
Selected Option: **Option X** because [reasons].

## Consequences
*   **Positive**: [Impact]
*   **Negative/Risks**: [Mitigations]
```
